## 1. Описание проекта 

Проект посвящен анализу активности пользователей сервиса доставки дронами. В ходе работы были выполнены:
	- Предобработка данных
	- Исследовательский анализ
	- Статистическая проверка гипотез
	- Построение дашборда
	- Прогнозирование суммы покупки с помощью линейно-регрессионной модели


## 2. Цель проекта

Исследовать поведение пользователей и покупателей, определить факторы, которые влияют на покупку и средний чек, а также проверить статистические гипотезы.

## 3. Данные

Источник - учебные данные
Объем 1013 пользовательских сессий
Основные столбцы:
	Юзер ID
	Регион пользователя
	Устройство пользователя
	Канал привлечения пользователя
	Начало, конец и длительность сессии
	Дата заказа
	Сумма заказа
	Тип оплаты

## 4. Используемые технологии

Для анализа данных выбран язык программирования python
Используемые библиотеки:
- Pandas - для удобной работы с датасетами
- Numpy - для приведения датасета к нужному виду для модели линейной регрессии
- Seaborn и matplotlib - для построения графиков в коде
- Scipy.stats - для расчета p-value для различных данных с различным распределением
	- p-value - метрика для определения возможности отвержения нулевой гипотезы
	- Нулевая гипотеза - предположение об отсутствии связи между данными
- sklearn - для построения модели линейной регрессии

## 5. Что было выполнено?

### ### Предобработка данных  
- Приведение названий столбцов к единому формату  
- Исправление ошибок и опечаток в категориальных данных  
- Приведение столбцов с датой и временем к корректному формату  
- Обработка пропусков в категориальных признаках  
- Обработка выбросов в длительности сессии и выручке  
- Удаление дубликатов  
- Создание новых признаков:  
	- `payer` — признак совершения покупки  
	- `sum` — сумма покупки с учетом промокода  
	- `time_of_day` — время суток
### Исследовательский анализ данных (EDA)  
- Расчет среднего чека для всех пользователей и отдельно для платящих  
- Анализ средней продолжительности сессии по каналам привлечения и устройствам  
- Сравнение среднего чека по устройствам, регионам и рекламным каналам  
- Анализ среднего количества покупок на пользователя  
- Анализ MAU по месяцам и каналам привлечения  
- Оценка эффективности рекламных каналов по числу пользователей, платящих пользователей и выручке  
- Анализ конверсии в покупку по регионам, устройствам и каналам привлечения  
- Анализ распределения покупок по типам оплаты  
- Анализ сезонности покупок по месяцам, дням недели и времени суток  
- __Визуализация ключевых закономерностей__  
### Проверка статистических гипотез  
- Проверка влияния типа устройства на среднее количество покупок  
- Проверка влияния рекламного канала на среднее количество покупок  
- Проверка различий среднего чека по регионам  
- Проверка различий среднего чека по рекламным каналам  
- Проверка различий среднего чека по времени суток  
- Проверка различий длительности сессии у платящих и неплатящих пользователей  
- Проверка связи между продолжительностью сессии и суммой покупки  
### Машинное обучение  
- Подготовка признаков для модели  
- Кодирование категориальных признаков с помощью OneHotEncoder  
- Разделение данных на обучающую и тестовую выборки  
- Обучение модели линейной регрессии  
- Оценка качества модели по метрикам R², MAE, RMSE и MAPE

## 6. Основные результаты анализа

По результатам анализа были получены следующие выводы:
- Наибольшая конверсия наблюдается у пользователей из США и Великобритании.
- Пользователи Android показывают более высокую конверсию по сравнению с другими устройствами.
- Основными источниками привлечения пользователей являются социальные сети и органический поиск.
- Самый популярный способ оплаты - Mobile Payments.
- Наибольшая пользовательская активность наблюдается в августе, по пятницам и в ночное время.

## 11. Запуск проекта

### Требования
- Python **3.12**
- pip
### Установка зависимостей

```bash
pip install -r requirements.txt
```
### Запуск проекта

```bash
python main.py
```

После запуска будут выполнены:
- загрузка и предобработка данных;
- исследовательский анализ данных (EDA);
- проверка статистических гипотез;
- построение и оценка модели машинного обучения;
- вывод результатов анализа.
